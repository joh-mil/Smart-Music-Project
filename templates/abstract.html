Abstract
The “Smart Music Using AI & ML” is an advanced music application developed to improve the normal music listening experience using Artificial Intelligence and Machine Learning technologies. The application can separate songs into different parts such as vocals, drums, and background music using the Demucs model. This helps users to extract background music, create karaoke tracks, and listen to instrumental versions of songs. The system also uses OpenAI Whisper technology to generate song lyrics automatically and display them in sync with the music, creating a karaoke-style experience for users.

The project also includes features like an AI Mashup Studio for combining songs smoothly and an Admin Module for managing songs and users. Most of the AI processing works locally on the device, which reduces internet usage and improves privacy. By combining Machine Learning with audio processing and a user-friendly interface, the Smart Music Player provides a smart, interactive, and modern way for users to enjoy digital music.
